# perchcat for Windows

桌面宠物 perchcat 的 Windows 移植: 一只橘猫站在你的窗口顶边和任务栏上, 窗口被拖走它会掉下来, 可以摸、拎起来、甩出去。
行为和数值与 macOS 版一致 (重力、甩出参数、按下手势、摸头、睡着掉落后抖毛再睡、地板升起时跳上去、全屏时地板落到屏幕底)。

只带内置的橘猫, 不读任何外部皮肤文件。

## 目录

| 目录 | 内容 |
| --- | --- |
| `PerchCat.Core` | 纯逻辑类库 (net8.0, 不依赖 WPF/Win32): 猫的状态机、平台几何、像素与逻辑点的换算、窗口过滤、开机自启逻辑、内置资源 |
| `PerchCat.Core.Tests` | xUnit 测试, 由 Swift 测试移植而来 |
| `PerchCat` | WPF 外壳 (net8.0-windows): 透明小窗口、读桌面布局、鼠标、托盘 |
| `scripts/extract_assets.py` | 从 Swift 的 `BuiltinSkin.swift` 重新生成 `PerchCat.Core/Assets/*.json` |

## 构建与测试

需要 .NET 8 SDK。Mac/Linux 上也能编译和发布 (`EnableWindowsTargeting`), 但只有 Windows 上能运行。

```
cd windows
dotnet test PerchCat.Core.Tests
dotnet publish PerchCat -r win-x64 -c Release --self-contained -p:PublishSingleFile=true
```

产物是 `windows/publish/PerchCat.exe` (单文件, 自带运行时, 已 gitignore)。拷到 Windows 双击即可, 无需安装。

内置资源 (皮肤 / 拎起帧 / 抖毛帧) 来自 Swift 常量, 修改了 `Sources/PerchCatCore/BuiltinSkin.swift` 后在仓库根目录跑:

```
python3 windows/scripts/extract_assets.py
```

## 使用

- 托盘图标右键: 藏起来 / 显示、开机自启、退出。双击托盘图标也能藏/显。
- 单击或在猫身上来回蹭 = 摸; 按住往上提 16 点以上 (且上提距离至少是横向的 1.5 倍) = 拎起来, 松手落下; 松手前快速挥动 = 甩出去。
- 开机自启只在勾选时写 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, 取消勾选就删除。
- 只允许一个实例。

## 与 macOS 版的差异

- 一只猫一扇小窗口 (贴着猫图, 含抖毛留白和气泡), 每帧移动; 不是铺满屏幕的覆盖层。
- 点和像素: 逻辑仍是 y 向上的"点", Windows 的物理像素 (y 向下) 通过 `PixelSpace` 换算。全桌面共用一个线性映射, 混合 DPI 下相邻屏的边在逻辑里仍相接, 猫走过去不会跳。代价: 猫的像素大小在所有屏上相同, 按启动时主屏 DPI 取整 (100% 一格 4 像素, 150% 一格 6 像素)。运行中改主屏缩放比例, 重启后生效。
- 平台: 可见、未最小化、未被 DWM 隐藏 (别的虚拟桌面)、非工具窗口、非本进程、非桌面/任务栏的顶层窗口, 取可见边框 (`DWMWA_EXTENDED_FRAME_BOUNDS`)。只读位置、状态位和窗口类名, 不读标题和内容。
- 地板: 每块显示器工作区的底边 (任务栏在哪条边都行, 自动隐藏也行)。整块屏被窗口铺满时地板落到屏幕底边。
- 屏幕顶部不需要留菜单栏高度 (`MenuBarSafe = 0`)。
- 跨屏的窗口两边都看得见, 所以在每块屏上各算一段平台。

## 未在真机验证

这些是在 Mac 上交叉编译的, 逻辑 (Core) 有测试覆盖, 但下面这些依赖真实 Windows, 尚未运行过, 需要人工过一遍:
透明窗口的点击穿透、不抢焦点、不进 Alt-Tab/任务栏、DPI 和混合 DPI 行为、托盘图标与菜单、开机自启写注册表、全屏检测、任务栏在不同边时的地板。

## 手动测试清单 (Windows, 比如 GPD 掌机)

- [ ] 启动: 双击 `PerchCat.exe`, 托盘出现猫图标, 桌面上出现猫, 站在任务栏上沿。再次双击 exe: 没有第二只猫。
- [ ] 不抢焦点: 在记事本里打字时点猫, 光标和输入焦点不丢; Alt-Tab 列表和任务栏里没有 perchcat。
- [ ] 点击穿透: 猫身体以外 (包括猫图透明的角落、气泡以外) 的位置可以正常点到下面的窗口和桌面图标。
- [ ] 点一下: 猫开始被摸 (眯眼); 在头上来回蹭几秒后变开心、踩奶; 持续摸约 30 秒会炸毛走开, 之后一分钟内不理你。
- [ ] 拖拽拎起: 按住猫往上提一小段, 猫被拎起 (一直拎着会越来越下垂); 按住横着拖只是蹭, 不会拎起。
- [ ] 甩出: 拎起后快速挥动鼠标松手, 猫飞出去, 撞到屏幕边会弹回; 慢慢松手则直接落下。
- [ ] 落脚: 把猫放在别的窗口顶边, 它站在上面; 拖动那个窗口, 猫跟着走; 把窗口拖走或关掉, 猫掉到下一层。
- [ ] 睡着掉落: 等猫自己睡着 (闲下来时有一半左右的概率), 拖走它脚下的窗口: 猫不跟着窗口走, 掉下来, 抖毛, 再坐下接着睡。睡着时帧率变低 (CPU 占用很小)。
- [ ] 全屏: 打开全屏视频/游戏 (或 F11 浏览器), 任务栏被盖住时猫落到屏幕最底边; 退出全屏后猫跳回任务栏上沿。
- [ ] 任务栏位置: 把任务栏分别放到底/顶/左/右, 以及开启自动隐藏, 猫的地板始终是工作区底边, 不会钻进任务栏下面。
- [ ] 最小化 / 虚拟桌面: 最小化猫脚下的窗口, 猫掉下去; 切换到另一个虚拟桌面, 那边的窗口不应成为平台。
- [ ] 多显示器 (有的话): 热插拔副屏时猫不消失 (被拔屏上的猫回到最近的地板); 猫能偶尔跳到相邻屏。
- [ ] 混合 DPI (有的话, 比如主屏 150% + 副屏 100%): 猫走过屏幕交界处不跳变、不闪; 图像边缘清晰 (像素没有糊); 窗口跨屏拖动时猫位置跟随正确。
- [ ] 托盘菜单: "藏起来"后猫消失、菜单变成"显示"; 再点恢复。"开机自启"勾选后注册表 `HKCU\...\Run` 出现 `PerchCat`, 取消勾选后该值被删除; 重新登录验证勾选时确实自启。
- [ ] 退出: 托盘 -> 退出, 猫和托盘图标都消失, 任务管理器里没有残留进程。
